# LinkedIn — Working guide

FortuneMarq's LinkedIn presence — B2B credibility + inbound from business owners who research agencies.
Right now this is **manual** (draft here, post by hand). `CONTEXT.md` = inventory/strategy; this file = how to work here.

## How it connects to the rest
- Inbound channel: profile/page visits + DMs → leads, tagged `source: linkedin` when they reach FMOS.
- Mostly a **personal-profile** game (the founder posting) — that's where B2B reach actually comes from.

## The manual workflow (now)
- Draft posts in `Posts/` (one file per post: hook, body, CTA, any link, post date).
- Cadence target: ~3×/week. Plain, credible, honest tone — share real lessons/results, no fluff.
- Post from the founder's personal profile and/or the Company Page in the LinkedIn app.

## ⚠️ Future plan — LinkedIn API (limited; keep mostly manual)
LinkedIn is **far more restricted than Meta** — automate only if it's clearly worth it:
- **Company Page posts** are automatable via the **Community Management API**, a *restricted* product you must apply for and get approved (harder than Meta App Review); scope `w_organization_social`; must be a Page admin.
- **Personal-profile posting via API is weak** — and personal profile is where most traction is. So API automation barely helps the main channel.
- API limits: ~100 calls/day/member. **No** document uploads, **no** polls, **no** clickable @mentions.
- **Verdict:** keep personal-profile posting manual; consider automating only Company-Page scheduling later, alongside the IG/FB build.
