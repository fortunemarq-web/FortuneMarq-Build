**Last Updated:** March 2026 | **Status:** Not started

## Purpose
Plan, script, and store all Reel content for FortuneMarq Instagram and Facebook. Reels are the highest-reach format — primary tool for follower growth.

## Reel Types
- Niche data reveal reels (hook: surprising search volume number)
- Behind the system reels (showing the tool, the PDFs, the process)
- AI tools demos (screen recordings with voiceover)
- Founder POV reels (Jabeer talking to camera)

## Reel Script Format
Each reel file contains:
- Hook (first 3 seconds — the line that stops scrolling)
- Body (the data or insight — 30–45 seconds)
- CTA (follow for more / WhatsApp us / link in bio)
- Caption (with hashtags)
- Visual notes (what to show on screen)

## File Naming
REEL_[Topic]_[Date].md
Example: REEL_Gyms_Hubli_30k_Searches_Mar2026.md
