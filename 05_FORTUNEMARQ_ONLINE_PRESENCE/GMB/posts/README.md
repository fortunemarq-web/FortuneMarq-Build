# posts/ — GMB post drafts

Draft ~2 posts/week here, then publish them manually in the Google Business Profile dashboard.
One file per post: `YYYY-MM-DD-short-topic.md`.

## Post template
```
Type: update | offer | event
Headline: (short, plain)
Body: (2–4 lines, business-owner friendly, one clear point)
CTA button: Call | Book | Learn more
Link: (if any)
Image: (filename in ../photos/ or a Drive link)
Status: draft | posted (date)
```

## Good FortuneMarq post angles
- A quick local marketing tip (honest, useful).
- A result/proof point (real only — no fake stats).
- A service spotlight (what it does for a Hubli business).
- An offer, when there is a genuine one.
