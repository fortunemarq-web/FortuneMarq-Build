# Campaigns — one folder per FortuneMarq ad campaign

Per-campaign planning lives here, organised by **city → niche** (FortuneMarq's own ads).

## How to start a campaign
1. Copy `_TEMPLATE/` → `<City>/<Niche>/` (e.g. `Hubli/dental-clinics/`).
2. Fill `plan.md`, `strategy.md`, `creative-brief.md`; log outcomes in `results.md`.
3. Destination URL = the matching niche LP: `https://fortunemarq.com/lp/<niche>/<city>`.

## Conventions
- Cities use real names; niches use the LP slug (e.g. `dental-clinics`).
- No ad-account tokens/credentials here. Real results only.
- Conversion tracking activation = `../conversion-tracking-checklist.md`.
