# SEO — Strategy

> DUMMY EXAMPLE.

## Goal
- Rank the clinic's service pages for high-intent Hubli dental terms (implants, braces, root canal).

## Approach
- On-page first (fast wins): map one target keyword per service page, fix technical issues, then publish
  helpful local content monthly to build topical authority.

## Inputs we're using
- Hubli dental keywords + search volumes (`07_DATA_AND_RESEARCH/Keyword_Data/Hubli_Keywords`).
- Competitor SERP data (`07_DATA_AND_RESEARCH/Competitor_Data`).

## Risks / watch-outs
- Starter tier = limited content output; set expectations that ranking is a 3–6 month build.
