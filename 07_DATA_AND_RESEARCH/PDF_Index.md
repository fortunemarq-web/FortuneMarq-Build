# FortuneMarq — PDF Index
**Last Updated:** 2026-06-22
**Purpose:** Describes how every Market Intelligence PDF maps to its city, niche, type, and language, and how FMOS automatically assigns the correct PDF to each lead based on their niche, city, and SERP status.

> **Source-of-truth index:** the canonical per-report index is now the **`report_assets`** table in Supabase (936 rows). This Markdown file documents the assignment logic and coverage; it does NOT attempt to mirror all 936 filenames. To look up a specific PDF, query `report_assets` (city, niche, type, language → storage path in the `market-reports` bucket).

---

## How PDFs Are Assigned to Leads

| Lead Segment | PDF Type | When to Send |
|---|---|---|
| SERP_Ranked = Y | Type 1 — Visibility Report | Lead already appears on Google Page 1 |
| SERP_Ranked = N, Has Website = N | Type 2 — Market Opportunity Report | Lead has no website and not on Google |
| SERP_Ranked = N, Has Website = Y | Type 3 — Website Performance Report | Lead has website but not ranking on Google |
| Any niche with volume under 2,500/month | Type 4 — Niche Market Report | Low search volume niche |

## PDF File Location
All PDFs are generated by the reportlab Python pipeline at `07_DATA_AND_RESEARCH/PDF_Generator` (the original 5-page editorial design: `pdf_generator.py` + `report_copy.py` + `kn_shape.py` + `generate_city_reports.py` + `batch_upload_reports.py` + `batch_upload_covers.py`), then uploaded to **Supabase Storage bucket `market-reports`** and served via the **`report_assets`** table. Kannada renders correctly via a HarfBuzz + FreeType shaper (`kn_shape.py`); reportlab alone cannot shape Kannada. This Python pipeline is the canonical report generator.
