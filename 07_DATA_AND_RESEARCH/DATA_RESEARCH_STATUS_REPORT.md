## 5. Data Quality Issues

### Issue 1 — `HUBLI_IELTS_COACHING1.csv` is a corrupt file
- **File:** `Lead_Database/Hubli_cleaned_leads/HUBLI_IELTS_COACHING1.csv`
- **Problem:** Contains CSS class names as headers (`fontBodySmall`, `ASWgTc`, `iOZr3b src` etc.) — this is raw HTML accidentally saved as CSV. 0 usable rows.
- **Impact:** Hubli has zero IELTS Coaching leads. The file should be deleted and the data re-scraped.

### Issue 2 — `Has Website` column shows Y for ALL Phase 1 leads (no N entries)
- **Files:** All 7 Phase 1 Hubli CSV files
- **Problem:** Every lead row shows `Has Website = Y`. This contradicts the CONTEXT.md claim that 2,282 businesses across the full database have no website. The Phase 1 files appear to have been scraped only from businesses that have website presence, OR the `Has Website` field was uniformly set to Y during standardisation.
- **Impact:** Cannot use Phase 1 Hubli files to segment the "no website" prospect pool.

### Issue 3 — `_ALL_RESULTS.json` covers only 10 of 14 niches
- **File:** `Competitor_Data/Hubli/_ALL_RESULTS.json`
- **Problem:** JSON contains keys for Gyms, Skin_Clinics, Computer_Training, Dental_Clinics, JEE_NEET_Coaching, Car_Rentals, Interior_Designers, Real_Estate, Physiotherapy, IVF_Clinics — but NOT for IELTS_Coaching, Modular_Kitchens, Tuition_Centres, or Hotels.
- **Impact:** PDF generator cannot produce PDFs for IELTS, Modular Kitchens, Tuition Centres, or Hotels from this JSON. Those 4 niches require separate data source.

### Issue 4 — Monthly search volumes marked TBD in SERP report for 13 of 14 niches
- **File:** `Competitor_Data/Hubli/Hubli_Master_SERP_Report.md`
- **Problem:** Only Gyms has a confirmed volume (30,000). All other 13 niches show "TBD" in the monthly volume column despite volumes being known from keyword data CSVs.
- **Impact:** The build_report.py script has volumes hardcoded for only 1 niche. The volumes from `Keyword_Data/` have not been merged into the SERP report.

### Issue 5 — Folder naming inconsistencies across cities
- **Problem:** City folders use inconsistent capitalisation and spelling: `Davangeri` (should be Davangere), `Manglore` (should be Mangalore), `manglore_cleaned_leads` (lowercase), `Kalburgi_cleaned_leads` (old spelling — should be Kalaburagi). The lead CSV files themselves use corrected names but the parent folders retain old spellings.
- **Impact:** Minor — does not break data but creates confusion in file paths and references.

### Issue 6 — Duplicate files between `Competitor_Data/serpdata/` and `Competitor_Data/Hubli/SERP_HTML/`
- **Problem:** Both locations contain identical Hubli SERP HTML files (14 files each). The `serpdata/` folder appears to be the original location before the SERP_HTML subfolder was created under Hubli.
- **Impact:** Wasted storage. The `serpdata/` folder should be reviewed and removed if confirmed duplicate.

### Issue 7 — `FortuneMarq_Master_Keyword_Research.xlsx` duplicated
- **Problem:** The same XLSX file (804-922 KB) exists in both `Keyword_Data/` and `Competitor_Data/` root.
- **Impact:** Minor — confusion about which is authoritative. One copy should be removed.

### Issue 8 — Dharwad keyword files with "empty" in filename
