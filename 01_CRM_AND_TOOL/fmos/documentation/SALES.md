# Sales Dashboard Documentation

## Overview
**URL:** `/sales`
**Primary User:** Sales Executives / Telecallers
**Purpose:** High-velocity lead processing, outcome logging, qualification, and follow-up management.

---

## 1. Quick Start Workflow
1. **Login** and navigate to `/sales`.
2. **Select Lead Type**: Use the top-left switcher — **Outbound (Cold)** or **Inbound (Hot)**.
3. **Filter by Niche / City / Website**: Use the top bar dropdowns to focus on a specific segment.
4. **Start Calling**: The cockpit presents leads one by one.
5. **Log Outcome**: After the call, click the result (e.g., "Connected" → "Interested").
6. **Follow-up Tab**: Switch to "Follow-ups" to work through scheduled callbacks — has its own reconnect script, last contact info, and notes reminder.

## 2. Interface Breakdown

### A. Top Bar — Filters & Navigation

| Control | Options | Notes |
|---|---|---|
| **Queue Tab** | Priority Calls / Follow-ups | Follow-ups tab shows live count badge |
| **Niche Dropdown** | All Niches / Dental Clinics / Gyms / etc. | Derived from actual leads in DB |
| **City Dropdown** | All Cities / Hubli / etc. | Derived from actual leads in DB |
| **Website Toggle** | All / Has Website / No Website | 3-button toggle for digital presence filter |

> **Removed in v3.9**: Turbo Mode button removed from UI (auto-advance logic retained internally).

---

### B. Lead Header (Calling Card)

**Business Name**
- Displays full name — wraps to 2 lines for long names (no truncation).

**Status + Score Row**
- Status badge (e.g., `New`, `Calling`, `Qualified`)
- Lead score badge (e.g., `Hot 8/10`, `Warm 5/10`)
- **Follow-up mode only**: "Last called Xd ago" badge + last outcome badge

**Tags Row**
Three types of pills displayed inline:
- **Auto-tags** (computed from DB fields, no storage needed):
  - `Has Website` (blue) — if `has_website = true` or `website_link` is set
  - `GMB Present` (green) — if `gmb_link` is set
  - `No Digital Presence` (red) — if neither website nor GMB
- **SERP tags** (stored in `lead.tags[]`, imported from CSV):
  - `SERP Ranked` (violet) — business ranks on Google
  - `Not SERP Ranked` (slate)
- **Manual tags** (amber) — added by telecaller during call via `+` button; removable with `×` on hover

**Notes Reminder** *(Follow-up mode only)*
- If lead has notes from a previous call, shown in an amber block above the dial button as a reminder.

**Action Buttons** (top-right of header, stacked vertically)
- `Visit Site` — opens `website_link` (shown only if link exists)
- `GMB Profile` / `Search` — always visible; opens GMB link if present, otherwise opens Google Search for `"Business Name City"`

**Contact Row**
- Contact person name + call attempt dots (up to 5 red dots showing attempt count)

---

### C. Dial Button & Call Actions

- **Dial Button**: Large tap-to-call button (`tel:` link). Shows "After Hours" warning if outside business hours.
- **Connected** → reveals:
  - Interested / Booked → moves lead to `Qualified`
  - Call Back Later → opens schedule modal
  - Not Interested → logs disqualification
- **No Answer** → logs attempt, keeps lead in `Calling`
- **Schedule** → opens date/time picker for follow-up
- **WhatsApp** → sends pre-approved niche-aware template

---

### D. Intelligence Section

**Priority Calls tab:**
- **Smart Pitch** — generated by local `pitch-engine` (no API key needed), personalised by niche + city + website status
- **Script / Objection Panel** — rebuttals for common objections
- **Activity Timeline** — full call history for the lead

**Follow-ups tab:**
- **Follow-Up Script** — reconnect-style script referencing company name, niche, city, contact person, and previous conversation
- **Script / Objection Panel** — same rebuttals available
- **Activity Timeline** — history shown for context

---

### E. Follow-Up Sidebar *(xl screens, right panel)*
Source: `follow_ups` table (separate from `next_action_date` on leads)

- Fetches all `status = "pending"` entries joined to `leads(company_name, contact_person, phone, industry, city)`
- **Priority sort**: Overdue → Today → Upcoming; within each group sorted by time ascending
- **Niche + City filter dropdowns** — filter sidebar list to a specific segment
- **Priority breakdown bar**: Shows counts — "2 Overdue · 3 Today · 5 Later"
- Each card shows: type icon (Call/WhatsApp/Email), time, business name, contact, **niche pill**, **city pill**, notes
- Card border colour: red = overdue, amber = today, white = upcoming
- One-click **Complete** or **→ open lead** in dialer

## 3. Lead Data in the DB (Relevant Columns)

| Column | Type | Source |
|---|---|---|
| `company_name` | text | CSV import |
| `phone` | text | CSV import |
| `industry` | text | CSV "Niche" column |
| `city` | text | CSV import |
| `has_website` | boolean | CSV "Has Website" Y/N |
| `website_link` | text | CSV "Website Link" |
| `gmb_link` | text | CSV "Google Maps Link" |
| `serp_ranked` | boolean | CSV "SERP_Ranked" Y/N |
| `serp_source` | text | CSV "SERP_Source" |
| `tags` | text[] | SERP tags on import + manual tags from telecaller |
| `lead_type` | text | `"outbound"` for Hubli leads |
| `status` | text | `"new"` on import → updated per call outcome |
| `last_contacted_at` | timestamptz | Updated on every logged outcome |
| `last_outcome` | text | Last call result (e.g. `"follow_up"`, `"no_answer"`) |
| `next_action_date` | timestamptz | Set when scheduling a callback |
| `attempts` | int | Incremented on every logged outcome |
| `notes` | text | Written during outcome logging |

---

## 4. CSV Upload Format

The in-app uploader (`/admin/upload`) and the Python import script both support:

```
Business Name | Phone | Has Website (Y/N) | Website Link | Google Maps Link | SERP_Ranked (Y/N) | SERP_Source | Niche | City
```

- `SERP_Ranked` / `SERP Ranked` (both accepted) → sets `serp_ranked` + adds "SERP Ranked" / "Not SERP Ranked" tag
- `SERP_Source` / `SERP Source` (both accepted) → sets `serp_source`

---

## 5. Outcome Logging Triggers

| Action | Status Update | DB Write |
|---|---|---|
| Interested / Booked | `qualified` | `lead_outcomes` insert |
| Call Back Later | `calling` | `follow_ups` insert + `next_action_date` set |
| No Answer | `calling` | `lead_outcomes` insert, attempts++ |
| Not Interested | `disqualified` | `lead_outcomes` insert |
| Book Strategy | `strategy_booked` | `leads.meeting_booked_at` set |

---

## 6. Keyboard Shortcuts
- `1`: Interested (Qualified)
- `2`: Follow Up / Call Back Later
- `3`: No Answer
- `4`: Not Reachable
- `5`: Not Interested (Disqualified)
- `S`: Book Strategy Session
- `→`: Next lead in queue
- `←`: Previous lead in queue
