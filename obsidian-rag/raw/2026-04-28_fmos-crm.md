# FMOS — FortuneMarq Operating System

FMOS is a full-stack agency CRM built from scratch by Jabeer. It is the single tool that runs the entire FortuneMarq business — no spreadsheets, no external tools. URL: fmos.fortunemarq.com

## Tech Stack
- Frontend: Next.js 16.1.6, TypeScript strict mode, Tailwind CSS v4
- Backend: Supabase (PostgreSQL, Project: cnwooodktqwvpzkucskm)
- Auth: @supabase/ssr v0.8.0 with server-side cookie sessions
- Charts: Recharts v3.5.1
- PDF Generation: @react-pdf/renderer
- AI: Claude API (claude-sonnet-4-20250514) for strategy engine
- AI: OpenRouter Mistral 7B for sales brain
- Icons: Lucide React, Animation: Framer Motion

## What's Built (~90% complete)
- Sales Intelligence Cockpit (power dialer, AI Brain, follow-up automation)
- Niche Pipeline Kanban (7-stage: new → contacted → interested → meeting → proposal → won/lost)
- Client Profile (7 tabs: Overview, Onboarding, Assets, Projects, Finance, Strategy, Communications)
- Task Board (Kanban: pending, not_started, in_progress, in_review, completed)
- Project Management (dashboard, task assignment, milestones)
- Strategy Engine (AI extracts tasks from strategy docs via Claude API)
- Finance Module (GST invoices FM-2026-XXX, expense tracking, P&L)
- Agency Marketing Module (content tracking, SEO keywords, ad campaigns)
- Global Search (Cmd+K, Postgres full-text)
- Client Portal (read-only client dashboard)
- WhatsApp Template Engine (17 templates, 5 categories)
- Notifications (Supabase Realtime)
- Audit Log
- 50+ database tables
